# Features Overview

Jovyan AI is packed with features designed specifically for data science teams.

## Core Features

### 🤖 Powerful Agents

Intelligent agents that plan, design, and execute complex data science tasks.

**What it does:**
* Breaks down complex requests into steps
* Executes multi-file operations
* Adapts to errors and edge cases
* Maintains context across conversations

[Learn more →](./powerful-agents.md)

### 📊 Data First

Data and notebooks are first-class citizens in Jovyan AI.

**What it includes:**
* Native Jupyter notebook support
* Automatic data validation
* Smart visualization generation
* DataFrame inspection and manipulation

[Learn more →](./data-first.md)

### 🔄 Data Science Methodology

Built-in data science best practices and workflows.

**What it provides:**
* Standard methodology (CRISP-DM, TDSP)
* Automatic data quality checks
* Reproducible analysis
* Professional documentation

[Learn more →](./workflows.md)

### 🎨 Multiple Modes

Specialized modes for different types of tasks.

**Available modes:**
* Data Analysis Mode
* Code Mode
* Debug Mode
* Custom Modes (unlimited)

[Learn more →](../using-jovyan/using-modes.md)
