# Keyboard Shortcuts

Quick reference for all Jovyan AI keyboard shortcuts and UI elements.

## Keyboard Shortcuts

| Action | macOS | Windows/Linux |
|--------|-------|---------------|
| Open/focus Jovyan AI panel | `Cmd+Shift+A` | `Ctrl+Shift+A` |
| Focus chat input directly | `Cmd+Shift+K` | `Ctrl+Shift+K` |
| Cycle through modes | `Cmd+.` | `Ctrl+.` |

## Sidebar Buttons

The Jovyan AI panel header contains these buttons:

| Button | Action |
|--------|--------|
| **+** (New Task) | Start a new task with a fresh context |
| **Prompts** | Access custom modes and rules |
| **History** | Browse and search past conversations |
| **Profile** | View your account, sign in/out |
| **Settings** | Open the settings panel |
| **Pop-out** | Open Jovyan AI in a VS Code editor tab |

### Pop-out Editor Panel

Click the **Pop-out** button to open Jovyan AI in a full editor tab instead of the sidebar. This gives you more screen space for reading long responses and reviewing diffs.

## Command Palette Commands

Open the Command Palette (`Cmd+Shift+P` / `Ctrl+Shift+P`) and search for "Jovyan":

| Command | Description |
|---------|-------------|
| `Jovyan AI: Open` | Open the Jovyan AI sidebar |
| `Jovyan AI: Export Settings` | Export your configuration to a JSON file |
| `Jovyan AI: Import Settings` | Import settings from a JSON file |
