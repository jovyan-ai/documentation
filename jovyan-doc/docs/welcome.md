# Jovyan AI Documentation

Jovyan AI **accelerates** data science development with AI-driven code generation and task automation. This extension plugs directly into VS Code for data science teams.

## What Can Jovyan AI Do?

* 🚀 **Generate Code** from natural language descriptions
* 📊 **Analyze Data** automatically with intelligent insights
* 🔧 **Refactor & Debug** existing code
* 📝 **Write & Update** documentation
* 🤔 **Answer Questions** about your codebase and data
* 🔄 **Automate** repetitive data science tasks
* 🏗️ **Create** new notebooks and projects

## Quick Start

1. [Install Jovyan AI](./getting-started/installing.md)
2. Set up your VS Code environment
3. Try Your First Data Science Task

## Features

### Basics

Use the chat interface to tell Jovyan AI what you need. It relies on coding-optimized AI models to complete each request.

* Switch modes to fit the task
* Control allowed actions
* Run direct code actions

### Using Jovyan AI

#### Multiple Modes

Jovyan AI adapts to your needs with specialized modes:

* **Data Analysis Mode:** For exploratory data analysis and insights
* **Code Mode:** For general-purpose coding tasks
* **Debug Mode:** For systematic problem diagnosis
* **Custom Modes:** Create unlimited specialized personas for data validation, model optimization, or any other task

#### Core Tools

Jovyan AI comes with powerful tools that can:

* Read and write files in your project
* Work with Jupyter notebooks natively
* Execute commands in your VS Code terminal
* Search your codebase
* Analyze data with built-in methodologies

See the complete [Tools Reference](./using-jovyan/tools.md) for all available tools.

### Data First

* **Jupyter Notebooks:** First-class support for notebooks
* **Data Validation:** Automated data quality checks
* **Visualization:** Automatic chart and plot generation
* **Data Science Methodology:** Built-in best practices

### Customizing Jovyan AI

Make Jovyan AI work your way with:

* Settings Management for configuring your experience
* Custom Modes for specialized tasks
* Custom Rules for project-specific rules
* Team Workflows for standardized processes
