# Jovyan AI Documentation

Jovyan AI **accelerates data science** by automating manual tasks, so your team can focus on innovation and impact. It integrates with VS Code, Cursor, Positron, and Windsurf as an AI agent that understands your code, notebooks, data, and visualizations.

## What Can Jovyan AI Do?

- **Work with Jupyter Notebooks** - Create, edit, and execute notebook cells through natural language. Jovyan AI understands cell outputs, charts, and images.
- **Explore and Analyze Data** - Load CSVs, Excel files, or Parquet, run EDA, build correlation matrices, and generate summary reports — all from a chat prompt.
- **Build and Debug Pipelines** - Write data pipelines, ML models, and scripts. Debug errors with full stack trace understanding.
- **Automate Housekeeping** - Clean datasets, refactor code, generate documentation, and create tests without breaking your flow.
