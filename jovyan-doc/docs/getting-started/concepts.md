# Core Concepts

Learn the key concepts used in Jovyan AI

| Concept                          | Description                                                                                                                                                                                                                                                           |
| -------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Provider**                     | Jovyan AI provides its own built-in API provider that gives you access to the latest frontier coding models without the need to manage API keys that offers access to frontier models such as: OpenAI (GPT-4), Anthropic (Claude), Google (Gemini), Meta (Llama) etc. |
| **Foundational Models**          | Large-scale AI models trained on vast datasets that serve as the base for AI applications. Models like GPT, Claude, LLaMA provide core language understanding and generation capabilities.                                                                            |
| **Prompt Engineering**           | Art and science of crafting effective inputs for AI models to achieve desired outputs. Use enhance button to improve your prompt                                                                                                                                      |
| **Modes**                        | Within Jovyan AI you can choose **Data Analysis** mode to explore and understand data, **Code** mode to write and refactor code, **Ask** to understand your codebase, **Debug** to fix software issues and **Orchestrator** to coordinate tasks across modes            |
| **Codebase Indexing**            | Codebase Indexing enables semantic code search across your entire project using AI embeddings.                                                                                                                                                                        |
| **Data Science Methodology**     | Structured approach to data analysis following best practices: data collection, exploration, preprocessing, modeling, evaluation, and deployment.                                                                                                                   |
| **Notebook Integration**         | Seamless integration with Jupyter notebooks, allowing AI-assisted cell generation, debugging, and optimization for data science workflows.                                                                                                                           |
| **Agent-Based Architecture**     | Jovyan AI uses specialized agents for different tasks: Data Analysis Agent, Code Generation Agent, Debugging Agent, and Documentation Agent.                                                                                                                         |
| **Workflow Automation**          | Automated data science workflows that can be customized and extended to handle complex analytical tasks with minimal manual intervention.                                                                                                                           |
| **Data-First Approach**          | Methodology that prioritizes data understanding and exploration before jumping into modeling, ensuring robust and reliable analytical results.                                                                                                                         |

## Data Science Specific Concepts

### Data Analysis Agent
Specialized AI agent designed specifically for data science tasks including:
- Data exploration and profiling
- Statistical analysis and hypothesis testing
- Feature engineering and selection
- Model evaluation and comparison

### Notebook Workflows
Enhanced Jupyter notebook experience with:
- AI-powered cell generation
- Intelligent code completion
- Automated documentation
- Interactive data visualization

### Data Pipeline Management
Tools for managing complex data workflows:
- ETL process automation
- Data quality monitoring
- Pipeline orchestration
- Error handling and recovery

### Statistical Modeling
Advanced modeling capabilities including:
- Supervised and unsupervised learning
- Time series analysis
- A/B testing frameworks
- Model interpretability tools

## Integration Concepts

### VS Code Integration
Deep integration with VS Code providing:
- Native file system access
- Terminal integration
- Extension ecosystem compatibility
- Seamless debugging experience

### Python Ecosystem
Full compatibility with Python data science stack:
- Pandas, NumPy, Matplotlib, Seaborn
- Scikit-learn, TensorFlow, PyTorch
- Jupyter, IPython, Notebook
- Virtual environment management

### Cloud Integration
Support for cloud-based data platforms:
- AWS, Azure, GCP integration
- Data warehouse connectivity
- Cloud storage access
- Distributed computing support
